# M.A.V.I.S. — 주식 종합 분석 스킬

**M**ulti-layered **A**sset **V**aluation & **I**nvestment **S**trategy

Claude Code에서 특정 주식·종목에 대한 7단계 종합 분석 보고서를 작성하는 스킬입니다.

## 분석 프레임워크

1. **거시 경제 및 시장 환경 분석** — 금리·인플레이션 지표, 경기 사이클, 시장 지수 동향
2. **상대 강도 및 섹터 분석** — 시장 대비 초과 수익, 섹터 내 위상
3. **기술적 분석** — 차트 패턴, 이동평균선, RSI/MACD/볼린저 밴드, 지지·저항
4. **수급 분석** — 기관/외국인/개인 매매 동향, 공매도·대차잔고
5. **펀더멘털 분석** — 밸류에이션, 성장성·수익성, 재무 안정성
6. **시장 심리 및 뉴스 분석** — 증권사 리포트, 뉴스·공시, 소셜 여론
7. **종합 시나리오 및 투자 전략** — Bull/Bear/Neutral 시나리오, 매수·관망 전략

## 설치

Claude Code에서 아래 두 명령을 실행하세요.

```
/plugin marketplace add kimdonghuyn/mavis-plugin
/plugin install mavis@mavis-plugin
```

## 사용법

```
/mavis 삼성전자
/mavis NVDA
```

종목명 또는 티커를 인자로 넘기면 오늘 날짜 기준으로 7단계 분석 보고서를 작성합니다.

## 면책 조항

본 스킬이 생성하는 보고서는 공개 데이터 기반 분석이며, 미래 주가를 보장하지 않습니다. 투자의 최종 책임은 투자자 본인에게 있습니다.
